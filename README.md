## 🚀 How to Run Locally / লোকালি যেভাবে চালাবেন

### পদ্ধতি ১: সরাসরি ব্রাউজারে ওপেন করুন
- ফোল্ডারের ভেতর থাকা `index.html` ফাইলটিতে ডাবল ক্লিক করুন। আপনার ডিফল্ট ব্রাউজারে (Chrome, Edge ইত্যাদি) সম্পূর্ণ ওয়েবসাইটটি ওপেন হয়ে যাবে।

### পদ্ধতি ২: Python লোকাল সার্ভার দিয়ে ওপেন করুন
টার্মিনালে বা PowerShell-এ এই কমান্ডটি রান করুন:
```bash
python -m http.server 3000
```
এরপর ব্রাউজারে `http://localhost:3000` এ ভিজিট করুন।

## 🌐 GitHub-এ আপলোড ও GitHub Pages লাইভ করার নিয়ম

আপনার ফ্রেন্ড বর্ষার মতো (`https://borshaosd.github.io/Portfolio/`) হুবহু সেম ভাবে আপনার লাইভ লিংক হবে:
👉 **`https://mfoishi5.github.io/Portfolio/`**

### ধাপ ১: GitHub-এ রিপোজিটরি তৈরি
1. আপনার ব্রাউজারে লগইন থাকা অবস্থায় [github.com/new](https://github.com/new)-এ যান।
2. **Repository name** দিন: `Portfolio`
3. এটি **Public** রাখুন এবং নিচে **"Create repository"** বাটনে ক্লিক করুন।

### ধাপ ২: ফাইল পুশ করা (সবচেয়ে সহজ উপায়)
ফোল্ডারের ভেতর থাকা **`push-to-github.bat`** ফাইলে ডাবল ক্লিক করুন।  
(যদি ব্রাউজারে অথোরাইজেশন চায়, একবার Authorize/Login করলেই সম্পূর্ণ কোড `https://github.com/mfoishi5/Portfolio`-তে পুশ হয়ে যাবে!)

### ধাপ ৩: GitHub Pages একটিভ করা (লাইভ লিংক পেতে)
1. আপনার রিপোজিটরির Settings-এ যান:  
   👉 `https://github.com/mfoishi5/Portfolio/settings/pages`
2. **Build and deployment** সেকশনে:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` এবং ফোল্ডার `/ (root)` সিলেক্ট করুন
3. **Save** বাটনে ক্লিক করুন।
4. ১-২ মিনিটের মধ্যে সাইটটি লাইভ হয়ে যাবে এই লিংকে:  
   🌟 **`https://mfoishi5.github.io/Portfolio/`**

## ⚡ Vercel-এ লাইভ করার নিয়ম (Vercel Deployment)

এই ওয়েবসাইটটিতে কোনো জটিল বিল্ড স্টেপ নেই, ফলে Vercel-এ ২ মিনিটে লাইভ হয়ে যাবে:

### পদ্ধতি ১: GitHub কানেক্ট করে (সবচেয়ে সহজ ও অটোমেটিক)
1. [vercel.com](https://vercel.com) এ লগইন করুন (Sign in with GitHub)।
2. **"Add New..."** -> **"Project"** এ ক্লিক করুন।
3. আপনার GitHub রিপোজিটরি `myesha-portfolio` সিলেক্ট করুন।
4. Framework Preset: **Other** বা ফাঁকা রাখুন (কারণ এটি পিওর HTML/CSS/JS)।
5. **Deploy** বাটনে ক্লিক করুন!
6. ৩০ সেকেন্ডের মধ্যে আপনার ফ্রি লাইভ লিঙ্ক তৈরি হয়ে যাবে (যেমন: `https://myesha-portfolio.vercel.app`)!

### পদ্ধতি ২: Vercel CLI দিয়ে সরাসরি কমান্ড লাইন থেকে
```powershell
npx vercel
```
ইনস্ট্রাকশন ফলো করে Enter চাপলে সাথে সাথে সাইট লাইভ হয়ে যাবে।
